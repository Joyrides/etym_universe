实际上是在设计一个双向词源索引系统：

                    ┌──────────────────┐
                    │     Word 表      │
                    │ 实际要学习的单词  │
                    └────────┬─────────┘
                             │
                    一个词 → 多个词源
                             │
                             ↓
                    ┌──────────────────┐
                    │   Etymology 表   │
                    │    词源/词根      │
                    └────────┬─────────┘
                             │
                    一个词源 → 多个单词
                             │
                             ↓
                    ┌──────────────────┐
                    │     Word 表      │
                    └──────────────────┘
正确表达「一个单词有多个词源，一个词源属于多个单词」

以 educate 为例：

educate
   │
   ├──────────────→ ex-
   │                  向外
   │
   └──────────────→ *deuk-
                      引导、领导

而从 *deuk- 出发：

                         *deuk-
                     “引导 / 领导”
                           │
             ┌─────────────┼─────────────┐
             ↓             ↓             ↓
         conductor      production     educate
          指挥/导体        生产          教育

所以数据库关系是：

Word
  │
  │ N:M
  ↓
Etymology
  │
  │ N:M
  ↓
Word

这就是典型的多对多关系。


通过 Universe 中只有这条路线发光：

                    ● 前缀词根ex-，意为向外
                   /
                  /
educate ✦                                                                               ● conductor（指挥、导体）
                  \                                                                            /
                   \                                                                         /
                    ● 原始印欧词根*deuk-，意为引导或领导
                                                                                             \
                                                                                               \
                                                                                                  ●production（生产）

其他节点全部变暗。
通过发光程度，节点大小，轨道距离，连线粗细，来表达关系强度。

在宇宙中画出一个词的历史轨迹。

推荐的数据结构
我会建议核心就是：
Word
Etymon
WordEtymon
其中：第一张表Word表示：
用户真正看到、搜索、学习的英语单词
例如：
educate
conductor
production
introduce
deduce


第二张表Etymon表示：
一个词源节点
例如：
ex-
*deuk-
education
每个节点带：
id
form
type
meaning
例如：
{
  "id": 123,
  "form": "*deuk-",
  "type": "root",
  "meaning": "to lead, guide"
}
type 非常重要可以简单成：
root
prefix
suffix

关键的第三张表：WordEtymon
这个表非常重要。
因为：
educate
可能：
educate
 ├── ex-
 ├── ducere
 └── *deuk-
所以不能：
words.etymology_id
这样只能表示一个词源。
应该：
words
   │
   │
word_etymons
   │
   │
etymons
例如：
words
────────────────
1 | educate

etymons
────────────────────────────
10 | ex-    | prefix
11 | *deuk- | root

word_etymons
────────────────────
word_id | etymon_id
1       | 10
1       | 11
这样 educate 就能关联多个词源节点。
